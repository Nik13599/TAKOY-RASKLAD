# ТАКОЙ РАСКЛАД — BALI Nightclub

Анонимная мобильная форма вопросов и закрытая админка специалиста для камеди-шоу.

## Адреса

- Гостевая анкета: `https://takoy-rasklad.kolyaselekh.workers.dev/`
- Админка: `https://takoy-rasklad.kolyaselekh.workers.dev/admin`

## Реализовано

- Выбор мужского / женского пола.
- Дата рождения в нативном календаре, автоматический расчёт возраста; **в базе хранится только возраст**.
- Выбор знака зодиака из 12 вариантов, подпись и символ.
- Анонимный вопрос (от 3 до 1200 символов).
- Анимация успешной отправки «Ваша анкета отправлена».
- Постоянная последовательная нумерация анкет с №1.
- Панель специалиста: крупный знак зодиака, возраст, пол, время и текст вопроса.
- Свайп влево/вправо между активными анкетами (новыми и отложенными).
- Автоматическая отметка первого просмотра; «Отложить вопрос» оставляет его в активной очереди и в статистике требующих внимания.
- «Разобрана» окончательно переносит анкету в отдельную историю с собственными свайпами; кнопки возврата в активную очередь нет.
- Проверка версии данных при открытии/возврате в браузер и раз в 20 секунд: если версия не изменилась, полный список не загружается.
- Серверное хранилище Cloudflare D1, доступ к просмотру и изменению ответов только после входа, ограничение скорости запросов, защита от CSRF.

## Развёртывание

Приложение загружено в Cloudflare Worker с именем `takoy-rasklad`, связанным с D1 `takoy-rasklad-questions` (регион хранения EU). Файлы `guest.html`, `admin.html`, `worker.js` — исходники, необходимые для обновления Worker; при развёртывании HTML встраивается в модуль `pages.js`.

### Обязательная завершающая настройка — пароль админки

**Админка останется закрытой до создания двух секретных переменных Worker.**

1. Войти в Cloudflare → Workers & Pages → `takoy-rasklad` → Settings → Variables and Secrets.
2. Создать **Secret** с именем `ADMIN_PASSWORD` и вашим новым длинным уникальным паролем.
3. Создать **Secret** с именем `SESSION_SECRET` и случайным секретом длиной не менее 32 байт, например 64 случайных шестнадцатеричных символа. Не использовать пароль администратора в качестве секретного ключа.
4. Сохранить и задеплоить конфигурацию.
5. Проверить вход по адресу `/admin` и отправить тестовую анкету с гостевой страницы.

Никогда не публикуйте эти значения в GitHub, в открытых переменных, в браузерном JavaScript или в ссылках.

## API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка работоспособности |
| POST | `/api/submit` | Анонимная отправка |
| POST | `/api/admin/login` | Вход специалиста |
| GET | `/api/admin/me` | Проверка авторизации |
| GET | `/api/admin/snapshot?version=N` | Получение очереди и истории; 204 без изменений |
| POST | `/api/admin/seen/:number` | Пометить первый просмотр |
| POST | `/api/admin/status/:number` | Отложить / разобрать |
| POST | `/api/admin/logout` | Выход |

### Хранение

Таблица `submissions` содержит только `number`, случайный идентификатор запроса, `gender`, `age`, `zodiac`, `question`, статус и временные отметки. Имя, e-mail, телефон и дата рождения не собираются. **Анонимность не означает невозможность косвенно идентифицировать автора по тексту его вопроса или сетевым логам провайдера.**

Статусы:
- `new` — новая; поле `seen_at` может быть заполнено после первого просмотра, но карточка остаётся активной.
- `postponed` — отложена и по-прежнему требует внимания.
- `resolved` — разобрана, доступна только в истории (сервер блокирует повторные изменения статуса).

Нумерация создаётся серверной базой; в публичной форме номер не раскрывается.

## Перед массовым использованием

- Проверить доступность сайта со смартфона по мобильному интернету.
- Выполнить интеграционный тест «гость → база → админ → отложить → разобрать → история».
- Проверить вместимость тарифа и требования по хранению, информированию и удалению персональных данных для вашего мероприятия.
- Настроить требуемый срок хранения и очистку анкет после мероприятия. Сейчас **автоматическая очистка не настроена**.
